# EPC Glossary

About 120 terms used in EPC projects and in this project, A–Z.
Details: [01_epc_fundamentals.md](01_epc_fundamentals.md) · EVM math: [03_evm_formulas.md](03_evm_formulas.md)

**Areas:** GEN = general / contracts · ENG = engineering · PRO = procurement ·
CON = construction / commissioning · DOC = document control · PC = project controls ·
QA = quality / safety

---

## A–C

| Term | Area | Meaning |
|---|---|---|
| **AACE** | PC | Association for the Advancement of Cost Engineering; defines the estimate classes 1–5 |
| **AC** (Actual Cost) | PC | Money actually spent on the work performed |
| **AFD** (Approved for Design) | DOC | Document status: can be used by other disciplines |
| **As-built** | DOC | A drawing updated to show what was actually built |
| **ASTM / ACI / AISC / ASME / API** | ENG | Standards bodies: materials testing / concrete / steel / pressure equipment and piping / oil and gas |
| **AVL** (Approved Vendor List) | PRO | Vendors allowed to bid |
| **BAC** (Budget at Completion) | PC | Total approved budget |
| **Baseline** | PC | The approved, frozen plan (scope, cost, schedule) used for comparison |
| **Bid tabulation** | PRO | Side-by-side comparison of vendor bids |
| **BOQ** (Bill of Quantities) | PRO | A list of work items with quantities, for pricing |
| **Brownfield / greenfield** | GEN | A project in an existing facility / on new, empty land |
| **CBE** (Commercial Bid Evaluation) | PRO | Comparing the prices and commercial terms of bids |
| **CBS** (Cost Breakdown Structure) | PC | Costs organized into cost accounts |
| **Change order / variation** | GEN | A formal change to scope, price or time |
| **Claim** | GEN | A request for extra money or time because of an event the other party is responsible for |
| **Commissioning** | CON | Starting up systems with real utilities and fluids |
| **Commitment** | PC | Money promised in POs and subcontracts but not yet spent |
| **Consortium / JV** | GEN | Several companies working together as one contractor |
| **Contingency** | PC | Budget for known risks inside the scope |
| **Control account** | PC | Where scope, budget, schedule and responsibility meet; the EVM measurement point |
| **CPI** (Cost Performance Index) | PC | EV / AC; < 1 = over budget |
| **CPM** (Critical Path Method) | PC | Scheduling method using activities, durations and logic links |
| **Critical path** | PC | The longest chain of dependent activities; a delay on it delays the project |
| **CRS** (Comment Resolution Sheet) | DOC | Reviewer comments and the responses to them |
| **CV** (Cost Variance) | PC | EV − AC |

## D–F

| Term | Area | Meaning |
|---|---|---|
| **Datasheet** | ENG | Technical requirements for one equipment item or instrument |
| **DBB** (Design-Bid-Build) | GEN | Traditional model: design first, then tender to builders |
| **DB** (Design-Build) | GEN | One contractor designs and builds |
| **Defects liability period** | GEN | Period after handover in which the contractor must fix defects |
| **Deviation** | PRO | Where a vendor's offer doesn't comply with the specification |
| **Discipline** | ENG | An engineering specialty: process, piping, civil, electrical, I&C… |
| **Division** | ENG | Top level of MasterFormat (e.g. 03 Concrete, 26 Electrical) |
| **Document control** | DOC | Managing document numbering, revisions, distribution and records |
| **EAC** (Estimate at Completion) | PC | Forecast final cost, e.g. BAC / CPI |
| **EDMS** | DOC | Electronic Document Management System (Aconex, SharePoint…) |
| **EPC** | GEN | Engineering, Procurement and Construction by one contractor |
| **EPCM** | GEN | EPC Management: the contractor manages P and C for the owner, usually reimbursable |
| **Equipment list** | ENG | A table of all equipment items with their tags and main data |
| **ES** (Earned Schedule) | PC | The time at which planned value equals the current EV |
| **ETC** (Estimate to Complete) | PC | EAC − AC: the money still needed |
| **EV** (Earned Value) | PC | Budgeted value of the work actually completed |
| **EVM** | PC | Earned Value Management |
| **Expediting** | PRO | Following up vendors to keep deliveries on time |
| **FAT** (Factory Acceptance Test) | PRO | Testing equipment at the vendor's factory before shipping |
| **Fast-tracking** | PC | Overlapping phases (e.g. construction starts before engineering ends) |
| **FEED** | ENG | Front-End Engineering Design: basic engineering before EPC |
| **FEL** (Front-End Loading) | GEN | Stage-gate process before project sanction (FEL-1/2/3) |
| **FIDIC** | GEN | International contract forms; the **Silver Book** is for EPC/Turnkey |
| **Float (slack)** | PC | How long an activity can slip without delaying the project |

## G–L

| Term | Area | Meaning |
|---|---|---|
| **GA** (General Arrangement) | ENG | A drawing showing the layout and location of items |
| **GMP** | GEN | Guaranteed Maximum Price contract |
| **Handover** | CON | Formal transfer of the facility to the owner |
| **Hold point / witness point** | QA | Inspection the work must stop for / that the client may attend |
| **HSE** | QA | Health, Safety and Environment |
| **HAZOP** | QA | Hazard and Operability study: a structured review of P&IDs for safety |
| **I&C** | ENG | Instrumentation and Control discipline |
| **IFA** (Issued for Approval) | DOC | Document status: sent for formal approval |
| **IFC** (Issued for Construction) | DOC | Final document status: can be built from |
| **IFR** (Issued for Review) | DOC | First issue, sent for comments |
| **Incoterms** | PRO | Rules for delivery responsibility and risk (FOB, CIF, DAP, DDP…) |
| **Instrument index** | ENG | A table of all instruments with their tags |
| **Interface** | GEN | A point where the work of two parties or disciplines meets; a frequent source of problems |
| **ISA-5.1** | ENG | Standard for instrument symbols and tag letters (F = flow, P = pressure…) |
| **Isometric** | ENG | Drawing of one pipe line for fabrication and construction |
| **ITB** | PRO | Invitation to Bid |
| **ITP** (Inspection and Test Plan) | QA | Lists inspections, tests and who must witness them |
| **LDs** (Liquidated Damages) | GEN | Pre-agreed money paid for delay or underperformance |
| **Licensor** | GEN | Owner of a process technology who supplies the basic design |
| **Line list** | ENG | A table of all pipe lines with size, service, pressure, temperature |
| **Long-lead item** | PRO | Equipment with a long manufacturing time, ordered first |
| **Loop check** | CON | Testing an instrument loop from the field device to the control system |
| **LSTK** (Lump-Sum Turnkey) | GEN | Fixed-price EPC; the plant is handed over ready to operate |
| **Lump sum** | GEN | A fixed-price contract |

## M–P

| Term | Area | Meaning |
|---|---|---|
| **Management reserve** | PC | Budget for unknown-unknowns, controlled by management |
| **MasterFormat** | ENG | The CSI/CSC system for organizing specifications into divisions and sections |
| **MC** (Mechanical Completion) | CON | Built and installed according to the design, static tests done |
| **MDR** (Master Document Register) | DOC | The list of all project documents with planned and actual dates |
| **Method statement** | CON | Describes how a work task will be performed safely |
| **Milestone** | PC | A key event with zero duration (e.g. "PO placed", "MC achieved") |
| **Monte Carlo simulation** | PC | Random simulation of risks to get cost and schedule probability ranges |
| **MR** (Material Requisition) | PRO | Engineering's technical request to buy items |
| **MRR** (Material Receiving Report) | PRO | Record of materials received at site |
| **MTO** (Material Take-Off) | ENG | Quantities measured from drawings and models |
| **NCR** (Non-Conformance Report) | QA | Records work or material not meeting the specification |
| **O&M manual** | DOC | Operation and Maintenance documentation for the owner |
| **OBS** | PC | Organizational Breakdown Structure |
| **OS&D** | PRO | Overage, Shortage and Damage report on delivered goods |
| **Owner / Client / Employer** | GEN | The party paying for and receiving the project |
| **P&ID** | ENG | Piping & Instrumentation Diagram: pipes, valves, instruments, control loops |
| **P50 / P90** | PC | Values with a 50% / 90% probability of not being exceeded |
| **Performance guarantee** | GEN | Contractual promise on capacity and efficiency |
| **Permit to work** | QA | Authorization for hazardous work |
| **PFD** (Process Flow Diagram) | ENG | Main process flows and equipment |
| **Plot plan** | ENG | Layout of the whole site or unit |
| **PMC** | GEN | Project Management Consultant acting for the owner |
| **PO** (Purchase Order) | PRO | Contract with a vendor |
| **Pre-commissioning** | CON | Checks without process fluids: flushing, loop checks, motor rotation |
| **Primavera P6** | PC | The standard scheduling software in EPC |
| **Progress measurement** | PC | Determining % complete (rules of credit, units completed…) |
| **Punch list (A/B)** | CON | Remaining defects; A = must fix before the next step, B = can fix later |
| **PV** (Planned Value) | PC | Budgeted value of the work planned to be done by now |

## Q–S

| Term | Area | Meaning |
|---|---|---|
| **QA / QC** | QA | Quality Assurance (systems and processes) / Quality Control (inspection and testing) |
| **RACI / RAM** | PC | Responsibility matrix: Responsible, Accountable, Consulted, Informed |
| **Re-baseline** | PC | Replacing the baseline after major approved changes |
| **Reimbursable (cost-plus)** | GEN | A contract paying actual cost plus a fee |
| **Revision** | DOC | A version of a document (A, B, C… then 0, 1, 2…) |
| **RFI** (Request for Information) | CON | A question to engineering about unclear or conflicting information |
| **RFQ** (Request for Quotation) | PRO | Request for vendors to submit prices |
| **RFSU** (Ready for Start-Up) | CON | Plant ready to introduce feed |
| **Risk register** | PC | A table of risks with probability, impact, owner and response |
| **Rules of credit** | PC | Fixed % credited per completed step (e.g. IFR 40%, IFC 90%) |
| **S-curve** | PC | Cumulative cost or progress over time, shaped like an S |
| **Schedule levels (1–5)** | PC | From milestone summary (L1) to detailed work (L4/L5) |
| **Scope of work** | GEN | Exactly what the contractor must deliver |
| **SD codes** | DOC | UFGS submittal types (SD-01 preconstruction … SD-11 closeout) |
| **Section** | ENG | A MasterFormat specification unit, e.g. `03 30 00` Cast-in-Place Concrete |
| **Shop drawing** | DOC | Detailed fabrication drawing made by a contractor or vendor |
| **SLD** (Single-Line Diagram) | ENG | Simplified diagram of the electrical power system |
| **SPI** (Schedule Performance Index) | PC | EV / PV; < 1 = behind schedule |
| **SPI(t)** | PC | ES / AT: time-based schedule index (works until the end) |
| **Specification** | ENG | Written technical requirements: materials, workmanship, testing |
| **Subcontractor** | GEN | A company doing part of the work under the main contractor |
| **Submittal** | DOC | A document sent for review/approval (product data, shop drawings, test reports…) |
| **Submittal register** | DOC | List of all required submittals and their status |
| **SV** (Schedule Variance) | PC | EV − PV |
| **System / subsystem** | CON | Commissioning units used for completion and handover |

## T–Z

| Term | Area | Meaning |
|---|---|---|
| **Tag number** | ENG | Unique identifier of an item, e.g. `P-101A`, `FIC-1001` |
| **TBE** (Technical Bid Evaluation) | PRO | Checking that bids comply with the technical requirements |
| **TCPI** (To-Complete Performance Index) | PC | Efficiency needed on the remaining work: (BAC − EV) / (BAC − AC) |
| **Transmittal** | DOC | Record of documents formally sent between parties |
| **Trend** | PC | An early warning of a potential change in cost or schedule |
| **UFGS** | ENG | Unified Facilities Guide Specifications (U.S. DoD); free on wbdg.org; our Module A data |
| **Unit rate** | GEN | Contract paying a price per unit of work × actual quantity |
| **VAC** (Variance at Completion) | PC | BAC − EAC |
| **VDR / VDRL** | PRO | Vendor Document Requirements List: documents the vendor must submit |
| **Vendor** | PRO | Supplier or manufacturer of equipment and materials |
| **Warranty** | GEN | The contractor's obligation to fix defects after handover |
| **WBS** (Work Breakdown Structure) | PC | The project scope broken down into deliverables and work packages |
| **Work package** | PC | The lowest level of the WBS, assignable and measurable |
