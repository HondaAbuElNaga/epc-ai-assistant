# Stage 1 Guide: EPC Domain Fundamentals

**Goal:** understand the EPC business well enough to explain *why* each module of this project
matters, and to talk confidently with engineers, project managers and project-controls staff in
an interview.

**Duration:** about 1 week (3–4 hours a day). No code in this stage.

**Output files:**
| File | Contents |

| [../02_glossary.md](../02_glossary.md) | About 120 EPC terms, A–Z |
| [../03_evm_formulas.md](../03_evm_formulas.md) | Earned value: every formula with a worked example, earned schedule, progress measurement, exercises |

## Study Plan

---

## How to Study

1. **Read actively.** After each section, close the file and write 3 key points.
2. **Look at real documents.** UFGS specs are free and real. Seeing one makes "specification"
   concrete.
3. **Connect each concept to a module:**
   - specification → Module A (RAG)
   - document types → Module B (classification)
   - P&ID → Module C
   - EVM → Module D
4. **Use the glossary** whenever a term is unclear.
5. **Practice explaining.** Say each answer out loud as if in an interview.
